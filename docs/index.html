The fine print

Reading the dials

01
Picture Profile

Saturation runs −8…+7 and hue −7…+7. PP LB/CC each run −9…+9: LB is amber (+) / blue (−), CC is magenta (+) / green (−).

02
White balance

Choose Auto, a fixed color temperature, or Preserve to leave the camera’s WB untouched. Temperature uses Kelvin ÷ 100, so 58 means 5800 K.

03
Camera labels

English menu labels are limited to 13 UTF-8 bytes, not 13 characters. Disabled looks return to their original stock names.

03 / From screen to camera

A careful, five-step install.

No firmware is flashed and the settings store is not rewritten. Read the full instructions in your extracted bundle before connecting the camera.

  1. 01

    Check the exact setup

    Confirm a Sony NEX-7 on firmware 1.03. Use a Mac with macOS, Homebrew, Python 3, a USB cable, and an SD card in the camera.

  2. 02

    Unzip your bundle

    Extract the default or customized ZIP. Keep its folder structure intact, then open Terminal in the extracted directory.

  3. 03

    Connect in Mass Storage mode

    Set USB Connection = Mass Storage on the camera. Connect USB and eject the card volume in Finder while leaving the cable attached.

  4. 04

    Run the installer

    ./install.sh

    The script installs local dependencies, performs its isolated Stage A test, installs under /setting, and requests a cold boot.

  5. 05

    Finish on the camera

    When the camera displays “OK to reset”, press OK. After the cold boot, open Creative Style and select your look.

A simple way back

Return to stock.

Connect in Mass Storage mode with the card ejected, then run this from the same extracted folder:

./uninstall.sh

The uninstaller removes the preload entry points and performs a read-only cold-boot session. Inert files left under /setting can remain.

If anything goes wrong: stop using the add-on and uninstall. Do not flash a recovery image or another firmware version.
