# Installation and recovery

## Requirements

- Sony NEX-7 with firmware **1.03**. Check the version before installing; other versions are untested.
- macOS with Homebrew, Python 3, and an internet connection for the first dependency install.
- A USB cable and an SD card in the camera.

## Install

1. Unzip `nex7-base-installer.zip` or your customized bundle.
2. Set **USB Connection = Mass Storage** on the camera.
3. Connect the camera and eject the card volume in Finder, leaving USB attached.
4. In the extracted directory, run:
   ```sh
   ./install.sh
   ```
5. The script:
   - checks Python and installs libusb if needed;
   - creates a local `.venv` with the USB dependencies;
   - uploads the add-on only to `/tmp` and runs the isolated Stage A process test;
   - installs the add-on, generated recipe config, and English string bank under `/setting`;
   - uses a **read-only** updater session to force a cold boot.
6. When the camera displays **“OK to reset”**, press **OK** on the camera.

No firmware is flashed. The settings store is not rewritten. The camera's own `Backup_read` API is used
only to read WB fields; recipe and WB changes use live camera messages.

## If the camera does not reconnect

- Confirm the USB mode is Mass Storage and the card volume is ejected.
- Disconnect and reconnect USB, then power the camera off and on normally.
- Retry the same command. Stage A does not change the boot files.

## Disable and return to stock

Run `./uninstall.sh` with the camera connected in Mass Storage mode and the card ejected. It removes
`/setting/env.txt` and `/setting/mode/dmode`, then performs the read-only cold-boot session. Files left on
`/setting` are inert without `LD_PRELOAD`.

## If something goes wrong

Stop using the add-on and run the uninstaller. Do not flash a recovery image or a different firmware
version. The add-on has a boot crash guard that disarms itself after repeated failed starts. If the guard
has tripped, the camera should remain stock; install only a build you have corrected and revalidated.
Do not delete the live guard while the add-on is running.

## Build artifacts

- `hook/nexhook-recipe.so`: preloaded add-on, version v17 in this distribution.
- `hook/nexhook-recipes.bin`: `NXR3` style/PP/WB mapping generated by `scripts/recipe_config.py`.
- `hook/string_english.uxc`: renamed English menu strings. Standard is deliberately unchanged.
- `scripts/service_cmds/`: isolated Stage A, installation, and stock-undo command files.

The web configurator changes only the latter two files. It does not patch the add-on binary or firmware.
